Este projeto reúne exercícios práticos de JavaScript com o objetivo de explorar como os dados e os elementos de uma página podem ser manipulados por meio do código.

Na primeira parte, são utilizados arrays e métodos como forEach, map, filter e reduce para percorrer listas, transformar informações, filtrar valores e calcular somas. Também são trabalhados arrays de objetos para representar produtos e seus preços.

Na segunda parte, o foco está na manipulação do DOM. O código altera o título da página, modifica a lista de tarefas, cria novos elementos e utiliza classes para identificar itens específicos.

Por fim, são explorados eventos de mouse, teclado e formulário. A lista de tarefas permite adicionar novos itens e alternar sua marcação como concluídos, utilizando também a delegação de eventos para lidar com os cliques nos elementos.

Tecnologias utilizadas: HTML5 e JavaScript.

Arquivos do projeto:

index.html — estrutura da página e seus elementos.

app.js — implementação dos exercícios e das interações.

Para executar, basta abrir o arquivo index.html em um navegador. O arquivo app.js deve permanecer na mesma pasta para que o código JavaScript seja carregado corretamente.

O projeto serve como prática dos fundamentos de JavaScript e como base para desenvolver páginas cada vez mais dinâmicas e interativas.
